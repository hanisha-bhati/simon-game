# Simon-Game
A fun and interactive Simon memory game built using HTML , CSS and JavaScript.

## Features
- Interactive gameplay
- Level progression
- High score tracking
- Random sequence generation
- User input validation
- Game-over detection
- New game / restart functionality

## How to play
1. Start the game.
2. Watch the sequence shown by the game.
3. Repeat the same sequence by clicking the buttons in the correct order.
4. With every successful round, the level increases.
5. If you select the wrong sequence ,the game ends.
6. Try to beat your high score!

##Technologies Used
- HTML5
- CSS3
- JavaScript
